## Changes and boundaries
- Reuse the existing broker identity fence on the EMA funds / margin-calculation / position read group. Reject auth-generation/account/token change, invalid exact FO key, unsafe quantity, invalid product, unsuccessful API response and a request lasting over 15s. Apply shared 12s fetch timeout. The POST to charges/margin is a read-only margin calculation, not an order. Capture conservative request-start time, not a manufactured exchange event clock.
- Strict decimal parsing rejects null, missing, empty, Boolean and nonfinite values. Require nonnegative available/used margin, positive required margin, valid portfolio P&L and normalized signed net quantity. Reuse strict account position row identity/cardinality guard; duplicate positions or contradictory quantity/net_quantity reject the entire response. Do not replace unavailable funds or positions with practice values. Margin sum is not independently verified NAV or capital history.
- Add reusable read-only order reconciliation and provider adapter method using exact order ID, instrument key, product, side, tag and requested quantity. Distinguish acknowledgement, partial open, terminal partial, terminal zero fill, full fill and unknown. Require order and per-trade quantities/average prices to agree; reject duplicate trade IDs and unknown/mismatched outcomes. Read order details and trades under a single local auth-generation fence; no placement, retry or cancel.
- Compare opposing terminal entry and offset fills only after exact intent match. Report residual quantity or offset-fill match; neither establishes account flat, permits retry or authorizes another order. Legacy records lacking identity cannot be silently reconciled. Adapter is an integration building block; existing legacy basket execution is not re-enabled and the new reconciliation policy is not yet wired into the unified gateway.
- Regression fixtures exercise numeric coercion, clock bounds, duplicate account rows, documented quantity normalization, partial/terminal/unknown outcomes, duplicate and contradictory trade evidence, residual exposure, wrong order identity and changed provider generation. All fixtures synthetic and read-only. No broker credentials or real orders used.
